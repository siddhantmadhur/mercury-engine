# Mercury project guide (CLAUDE.md)

This is a Mercury game project, open in the Mercury editor, which runs an opt-in MCP server so Claude Code can inspect and change the project. This guide was generated by that server from the live project; it is not a file in the project.

## Connecting from Claude Code

Add the server once (use the real token from **File > Preferences > MCP**, which also has this command ready to copy):

```sh
claude mcp add --transport http mercury {{url}} --header "Authorization: Bearer <token>"
```

Then run `/mcp` inside Claude Code to check that `mercury` is connected.

- Server URL: `{{url}}`
- The token is not written into this guide: replace `<token>` with the one shown in **File > Preferences > MCP**.
- Edits: {{edits}}
- If **File > Preferences > MCP** has "Auto-write .mcp.json" on (the default), the editor keeps a `mercury` entry in the project's `.mcp.json` while it runs, which Claude Code can pick up from the project folder. That entry contains the token, so keep `.mcp.json` out of version control.
