# Mercury project guide (AGENTS.md)

This is a Mercury game project, open in the Mercury editor, which runs an opt-in MCP server so an AI agent can inspect and change the project. This guide was generated by that server from the live project; it is not a file in the project.

## Connecting

- Server URL: `{{url}}`
- Authentication: send the header `Authorization: Bearer <token>` with every request. The token is not written into this guide. Copy it (or the ready-made command) from **File > Preferences > MCP** in the editor.
- Edits: {{edits}}
- If **File > Preferences > MCP** has "Auto-write .mcp.json" on (the default), the editor keeps an entry for this server in the project's `.mcp.json` while it runs. That entry contains the token, so keep `.mcp.json` out of version control.
