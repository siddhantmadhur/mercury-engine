# Mercury project guide (GEMINI.md)

This is a Mercury game project, open in the Mercury editor, which runs an opt-in MCP server so Gemini CLI can inspect and change the project. This guide was generated by that server from the live project; it is not a file in the project.

## Connecting from Gemini CLI

Add the server to Gemini CLI's `settings.json` (the project's `.gemini/settings.json` or your user-level `~/.gemini/settings.json`):

```json
{
  "mcpServers": {
    "mercury": {
      "httpUrl": "{{url}}",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

- Server URL: `{{url}}`
- The token is not written into this guide: replace `<token>` with the one shown in **File > Preferences > MCP**. A `settings.json` holding the token should not be committed.
- Edits: {{edits}}
